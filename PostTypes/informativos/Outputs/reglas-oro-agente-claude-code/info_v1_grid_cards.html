9 reglas de oro para crear
un agente con Claude Code

Lo que separa a un usuario promedio de un power user

1
Empieza por el CLAUDE.md
Es el cerebro de tu agente. Define contexto, reglas y personalidad ahí antes de cualquier otra cosa.
2
Sé específico, no genérico
"Refactoriza el auth" falla. "Mueve JWT a middleware/" funciona. El agente necesita instrucciones claras.
3
Usa subagentes en paralelo
Divide tareas complejas en agentes especializados que trabajen al mismo tiempo. Multiplica velocidad.
4
Configura los hooks
Scripts automáticos que se ejecutan antes/después de cada herramienta. Validan sin intervención tuya.
5
Activa Extended Thinking
Para tareas que requieren planificación. Fuerza al modelo a pensar antes de actuar. Menos errores.
6
Estructura tus carpetas
El agente necesita encontrar lo que busca. Carpetas claras con convenciones > archivos sueltos.
7
Itera, no pidas todo
Una tarea, revisa, ajusta, siguiente. No pidas "hazme toda la app". El contexto se pierde.
8
Controla los permisos
Decide qué herramientas puede usar sin preguntar y cuáles requieren tu aprobación manual.
9
Mantén el contexto limpio
Edita mensajes en vez de enviar nuevos. Cada follow-up consume tokens y diluye el foco.
